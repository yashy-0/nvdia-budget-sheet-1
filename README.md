# nvdia-budget-sheet-1

Files

Personal_Budget.xlsx A monthly budget with income, expenses by category, and a savings section. There's also an investment tracker tab with NVDA set up as an example holding. Yellow cells are where you plug in your own numbers, everything else calculates on its own.

NVIDIA_Balance_Sheet.xlsx NVIDIA's balance sheet pulled from their most recent 10-Q filing with the SEC, showing two periods (July 2026 and January 2026) side by side. Includes totals, a balance check, and a few basic ratios like current ratio and debt-to-equity.
